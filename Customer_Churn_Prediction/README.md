# Customer Churn Prediction

## Objective
Predict whether a customer is likely to leave a service using historical customer data.

## Technologies
Python, Pandas, Scikit-learn, Logistic Regression, Streamlit.

## How to run
1. Install Python.
2. Open this folder in VS Code.
3. Run:
   `pip install -r requirements.txt`
4. Train the model:
   `python train_model.py`
5. Start the app:
   `streamlit run app.py`

## Resume description
Built a machine-learning customer churn prediction system using Pandas and Scikit-learn. Applied preprocessing, one-hot encoding, logistic regression, model evaluation, and created a Streamlit interface for predictions.
